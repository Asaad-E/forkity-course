Forkify is a JavaScript-based web application for searching, viewing, and managing recipes. This project is part of the JavaScript Udemy course and focuses on modern JavaScript features, asynchronous programming, and working with APIs.

## Features

- Search for recipes using the [Forkify API](https://forkify-api.herokuapp.com/).
- View detailed recipe information, including ingredients and cooking time.
- Adjust the number of servings dynamically.
- Bookmark favorite recipes for quick access.
- Add custom recipes to the application.
- Responsive design for various screen sizes.

## Technologies Used

- JavaScript (ES6+)
- HTML5 & CSS3
- Webpack (module bundler)
- Babel (JavaScript compiler)
- Axios (HTTP requests)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/forkify.git
   ```
2. Navigate to the project directory:
   ```bash
   cd forkify
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```

## Usage

1. Open the application in your browser at `http://localhost:8080`.
2. Use the search bar to find recipes by keyword.
3. Click on a recipe to view its details.
4. Adjust servings or bookmark recipes as needed.

## Folder Structure

- `/src`: Contains the source code.
  - `/js`: JavaScript modules for the application.
  - `/css`: Stylesheets for the application.
  - `/img`: Images and icons.
- `/dist`: Bundled files for production.

## API Reference

This project uses the [Forkify API](https://forkify-api.herokuapp.com/) to fetch recipe data. Refer to the API documentation for more details.
